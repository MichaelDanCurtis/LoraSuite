# 0.1.0 public preview — 29 October 2026

First public source release of LoraSuite, with the optional unpacked Chrome companion.

- Guided and Advanced share model recipes, project media and review records.
- Saved source libraries remain visible when resuming a project.
- Detailed import, preparation, identity and dataset controls are available inside Guided.
- Project-scoped work, provider handoffs and evaluation support are included.
- LoRA Manager integration delegates to the external application.
- Consistent navigation controls and a visual six-stage workflow.
- Local browser-origin checks and updated frontend and engine dependencies.

## Preview boundaries

Not all model/provider combinations have passed a real training and evaluation run. Experimental recipes are labeled. Ask AI is currently rule-based workflow help. Unconfirmed intake drafts differ between Guided's popup and detailed ingress; imported project records are shared. Intermittent engine connection failures observed in earlier local checks have retry controls, but their underlying cause has not been fully established.

The release assets contain source and an unpacked companion, not a notarized desktop installer. Desktop source builds are supported for development. Signed/notarized distribution, clean-machine installation and live updater/rollback qualification remain separate release gates. No claim is made that Windows or Linux desktop lifecycle qualification is complete.
